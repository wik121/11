    How this works & offline notes

    Whisper AI engine: the Whisper speech model runs inside your browser — audio never leaves your device. The first use downloads the model once; your browser caches it, and after that transcription works offline.

    Browser dictation engine: uses your browser's built-in speech recognition. It is instant and very accurate, but on some browsers (e.g. Chrome) the audio is processed by an online service — choose the Whisper engine if you want everything strictly on-device.

    Phones: browsers only allow microphone access on secure pages. If the mic button does nothing when opening this file directly, serve the file over HTTPS (for example free GitHub Pages) or via a local server, then open that address on your phone. You can also "Add to Home Screen" to use it like an app.

    Privacy: settings and history are stored only in this browser (local storage). Nothing is uploaded; there are no analytics or accounts.

    Getting text into other apps: web pages can't type into other apps, so tap Copy (or any history row) and paste where you need it.
